# Every compound identifier this repository is permitted to say in an *example* position — a fixture, a
# string literal, a doc comment, a document. Checked by SiftCoreTests' example-name suite over every file
# in the tree on every run, and so on every push.
#
# **The tree is what git tracks plus what it neither tracks nor ignores**, so a file fails the gate on the
# day it is written rather than the day it is staged — a scratch file nobody means to commit included. The
# one way out is the one git already has: a path covered by `.gitignore` is a path the gate does not read.
# If you want a file this list does not govern, ignore it in git; do not leave it merely uncommitted.
#
# This is a permit list, and its being one is the point. The gate beside it — private-terms.txt with
# verify-private.sh and verify-tree.sh — bans what it can enumerate: a handful of generic phrases, and
# the names of the directories sitting beside the checkout, discovered at run time. A leak gets past a
# blocklist whenever the name it needs is one the list structurally cannot name. A masked product
# invented for a fixture is nobody's neighbouring directory. Neither
# is a codebase belonging to somebody else, and that one reads *more* ordinary than an invention
# rather than less, so no reviewer's eye stops on it either. Enumerating what is allowed is the only
# form of this check that closes, because the thing it has to notice is a name arriving that nobody
# put here on purpose.
#
# **This file is published, and it is safe to read.** Every entry is one of exactly two things: a
# placeholder invented for this repository's examples — Gizmo, Depot, Orchard, Catalogue, Alpha and
# Beta, and the warehouse vocabulary the run-output fixtures are built out of — or public framework
# API, SwiftSyntax and HealthKit and the rest, which name nothing that is not already in Apple's own
# documentation. Read end to end, it says what this repository invents. It says nothing about what
# else is on the machine it was written on, and that is a property to keep rather than a coincidence.
#
# **A real name never goes on this list.** When the gate names an identifier, exactly two answers are
# legitimate:
#
#   * rename the fixture to a placeholder this list already carries — that is what the placeholders
#     are for, and reusing one costs nothing;
#   * the name is newly invented, so add it here, in the same commit as the fixture that needs it.
#
# Adding a name that belongs to something real — a product, a client, a repository that exists — is
# not a repair. It is publishing the leak and switching off the alarm that found it. That is the one
# use of this file there is no version of that is acceptable.
#
# Sorted, one name per line, byte order, and pruned when the last example using a name goes: a commit
# that adds a line here is the diff a human should stop and read, and it only reads that way while the
# list stays short enough to have been read. The suite asserts both directions — nothing in the tree
# that is not here, nothing here that is not in the tree.
#
# Names this repository *declares* are deliberately absent. Those are code: the compiler governs them,
# a rename is a build error, and a permit list obliged to carry every one of them would fire
# on an ordinary morning's work and be switched off inside a week.
